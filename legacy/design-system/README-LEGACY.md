# Legacy 说明（design-system）

> 最后更新：2025-12-03

该目录包含 2024 年的设计 token、Tailwind 主题和组件示例，仅作为参考样本。当前 App Router 项目不会在构建阶段加载这里的文件。

保留目的：

1. 记录旧版视觉语言与 token 定义；
2. 协助对接设计团队时对比“旧 vs 新”配色方案；
3. 作为迁移文档（见 `README.md` 与 `ADVANCED_FEATURES.md`）。

操作提示：

- 如需沿用其中的 token/样式，请先在 `src/styles` 或 `src/components` 中重建，并更新 `docs/standards`；
- 如果未来要清理或迁移，请更新 `docs/project-governance/file-archive-log.md` 并在 PR 中说明；
- 正式项目入口请参考仓库根目录下的 `src/`、`docs/standards/` 与 `docs/rixinmath-coarse-to-fine-interface.md`。
