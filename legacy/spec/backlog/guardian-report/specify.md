# 家长汇报模式 - Specify

## Meta
- **Slug**: guardian-report
- **Owner**: Hugo / PM
- **Status**: designing
- **Last Update**: 2025-11-14

## 背景
- 教学老师需要向家长/校方展示“10 分钟组卷、批改提效 50%”以及学生进步，但当前学情页只面向教师内部。
- 项目 KPI 要求 Beta 满意度 ≥4/5，且 PM 经常通过截图向家长解释，流程重复低效。

## 用户痛点 / 动机
- 老师无法快速把学情分析转成“可分享故事”，导致成果证明困难。
- 班主任/运营同样需要统一口径的周报，减少手写 PPT。

## 目标 & 成功标准
- 60 秒内生成可分享的“家长汇报链接/PDF”。
- 汇报包含：课堂故事、错题回顾、下一步建议，并允许自定义称谓/品牌抬头。
- 保障权限：仅被邀请的家长可访问，访问记录可追踪。

## 需求描述
- 在“学情分析”页新增【生成家长汇报】按钮。
- 支持两个模板（故事板版/数据摘要版）+ Logo/签名设置。
- 生成分享链接（短链 + token）或导出 PDF。
- 可查看访问记录，管理员可立即撤销链接。

## 约束与非目标
- 必须引用真实的成绩/错题/建议数据，禁止手写假数据。
- 首版不做家长端登录，仅 token 访客访问。
- 不涵盖家长评论/互动功能。

## 依赖
- `analytics` 模块中的知识点/成绩数据。
- Supabase `reports` 新表。
