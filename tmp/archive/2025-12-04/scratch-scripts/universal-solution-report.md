## 🎯 核心目标

实现一套**通用化、零规则**的解决方案，能够自动处理：
- ✅ 不同版式（单栏 / 双栏）
- ✅ 不同布局（图在左 / 右 / 下 / 中间）

**不需要**：

- ❌ 人工标注图片位置
- ❌ 针对特定版式调参

## 📊 改造内容

### 1. Prompt 通用化改造

#### 改造前（针对性）
```
**定位规则**：
- 数学试卷中的插图通常位于题目的**右侧**或**下方**
```
**问题**: 硬编码了"右侧或下方"的规则，无法适应图在左侧或中间的情况

#### 改造后（通用化）
```
【核心工作流】
1. **版式自适应**：
   - 先判断是单栏还是双栏
   - 如果是双栏，严格按照"先左栏→后右栏"的顺序读取
   - 如果是单栏，按从上到下的顺序读取

2. **题目边界识别**：
   - 利用题号作为锚点，精准切割独立题目

3. **图文自动关联**：
   - 扫描该题目空间范围内的所有视觉元素
   - 你的视觉系统非常敏锐，能自动发现图片位置（左/右/下/中间）
   - 返回图片的边界框，确保包含完整的图形区域
```

**改进点**：
- ✅ 从"规则驱动"改为"视觉驱动"
- ✅ 让AI自己判断图片位置，而不是告诉它"图在哪里"
- ✅ 强调"空间范围内的视觉元素"，不限定方向
- ✅ 添加双栏处理逻辑（防止顺序错乱）

### 2. 裁剪代码通用化改造

#### 改造前（基础版）
```typescript
const left = Math.max(0, Math.round(x));
const top = Math.max(0, Math.round(y));
const maxWidth = Math.min(Math.round(width), imageWidth - left);
const maxHeight = Math.min(Math.round(height), imageHeight - top);

await sharp(buffer).extract({ left, top, width: maxWidth, height: maxHeight })
```
**问题**:
- 没有padding，可能切掉图形边缘
- 边界检查不完善

#### 改造后（通用防呆版）
```typescript
// 🛡️ 智能容错：添加padding防止边缘被切掉
const PADDING = 10; // 10像素的安全边距

// 计算带padding的裁剪区域
let left = Math.round(x) - PADDING;
let top = Math.round(y) - PADDING;
let right = Math.round(x + width) + PADDING;
let bottom = Math.round(y + height) + PADDING;

// 🛡️ 智能容错：防止坐标越界
left = Math.max(0, left);
top = Math.max(0, top);
right = Math.min(imageWidth, right);
bottom = Math.min(imageHeight, bottom);

// 🛡️ 智能容错：防止切出空图或负数尺寸
const finalWidth = right - left;
const finalHeight = bottom - top;

if (finalWidth <= 0 || finalHeight <= 0) {
  console.warn('无效坐标，跳过');
  continue;
}

await sharp(buffer).extract({ left, top, width: finalWidth, height: finalHeight })
```

**改进点**：
- ✅ 添加10px padding，防止切到边缘
- ✅ 完整的边界检查（防止越界）
- ✅ 尺寸验证（防止空图或负数）
- ✅ 详细的错误日志
