#### 2. 数据库存储验证
**优先级**: P0
**预估时间**: 15分钟

**任务内容**:
- [ ] 通过UI爬取数据后，检查数据库
- [ ] 验证 `xhs_raw_posts` 表中数据完整性
- [ ] 验证新字段 `collects` 和 `publish_time` 已保存
- [ ] 验证RLS策略：用户只能看到自己爬取的数据

**验证SQL**:
```sql
-- 查询最新爬取的帖子
SELECT
  post_id,
  title,
  likes,
  collects,         -- 验证收藏数
  publish_time,     -- 验证发布时间
  crawl_keyword,
  created_at
FROM xhs_raw_posts
ORDER BY created_at DESC
LIMIT 5;

-- 验证字段覆盖率
SELECT
  COUNT(*) as total,
  COUNT(collects) as has_collects,
  COUNT(publish_time) as has_publish_time,
  ROUND(COUNT(collects)::numeric / COUNT(*) * 100, 2) as collects_coverage,
  ROUND(COUNT(publish_time)::numeric / COUNT(*) * 100, 2) as publish_time_coverage
FROM xhs_raw_posts;
```
