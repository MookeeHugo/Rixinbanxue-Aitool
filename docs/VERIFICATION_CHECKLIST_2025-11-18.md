## 常见问题排查

### 问题 1: 某些文字仍然不清晰

**可能原因**:
- 浏览器缓存未清除
- CSS 文件未重新编译

**解决方案**:
```bash
# 1. 硬刷新浏览器
# 按 Ctrl+Shift+R (Windows) 或 Cmd+Shift+R (Mac)

# 2. 清除 Next.js 缓存
rm -rf .next
# Windows PowerShell:
Remove-Item -Recurse -Force .next

# 3. 重启开发服务器
npm run dev
```

---

### 问题 2: 页面加载仍然很慢

**可能原因**:
- Turbopack 未成功启动
- 仍在使用旧的 Webpack 编译器

**检查方法**:
```bash
# 查看开发服务器日志
# 应该显示 "Next.js 14.2.7 (turbo)"
# 而不是 "Next.js 14.2.7"
```

**解决方案**:
```bash
# 1. 确认 package.json 中的 dev 脚本包含 --turbo
npm run dev

# 2. 如果 Turbopack 有问题，回退到 Webpack
npm run dev:legacy
```

---

### 问题 3: 登录后访问页面返回 401

**可能原因**:
- 测试账号未创建
- Supabase 本地服务未运行

**解决方案**:
```bash
# 1. 检查 Supabase 状态
npx supabase status

# 2. 如果未运行，启动 Supabase
npx supabase start

# 3. 创建测试账号
NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321 \
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... \
node scripts/create-test-users.mjs
```

---

### 问题 4: Turbopack 启动失败

**错误信息**: `Unsupported Next.js configuration option`

**解决方案**:
- 该问题已在配置中修复
- 如果仍有问题，使用 `npm run dev:legacy` 回退到 Webpack
