## 🎨 对比度检查指南

### 使用 Chrome DevTools 检查对比度

#### 1. 打开 DevTools
1. 按 `F12` 或右键点击 "检查"
2. 切换到 **Elements** 标签

#### 2. 检查元素对比度
1. 在 Elements 面板中选中要检查的元素（如按钮、文字）
2. 查看右侧 **Styles** 面板
3. 找到颜色值旁边的小色块，点击它
4. 在颜色选择器底部查看 **对比度信息**

#### 3. 对比度标准 (WCAG)

**AA 级别（最低要求）**
- 正常文字（<18pt）：对比度 ≥ 4.5:1
- 大字体（≥18pt 或 ≥14pt 粗体）：对比度 ≥ 3:1
- UI 组件和图形：对比度 ≥ 3:1

**AAA 级别（增强）**
- 正常文字：对比度 ≥ 7:1
- 大字体：对比度 ≥ 4.5:1

### 关键配色对比度验证

#### 主按钮 (Primary Button)
```
青葱绿背景 #0AA344 + 白色文字 #FFFFFF
预期对比度: ~3.5:1 (AA 大字体通过 ✓)
```

检查方法：
1. 找到任意主按钮（如导航栏 "注册" 按钮）
2. 右键点击 → 检查
3. 在 Styles 面板找到 `background-color: #0AA344`
4. 点击颜色色块，查看与白色文字的对比度
5. 确认对比度 ≥ 3:1

## 🐛 常见问题排查

### 问题 1: 颜色未生效
**症状**: 某些组件仍显示旧的蓝色

**解决**:
1. 清除浏览器缓存 `Ctrl+Shift+Delete`
2. 硬刷新页面 `Ctrl+Shift+R`
3. 检查是否有硬编码的颜色值（如 `#0052D4`）

### 问题 2: 对比度不足
**症状**: 文字难以阅读

**解决**:
1. 使用 DevTools 检查实际对比度
2. 如果 < 3:1，调整颜色深度
3. 考虑使用更深的 `primary-700` 或 `accent-700`

### 问题 3: 焦点环不可见
**症状**: Tab 导航时看不到焦点指示器

**解决**:
1. 检查 `globals.css` 中的焦点样式
2. 确认 `ring-primary-500/20` 生效
3. 可能需要增加透明度或使用更深的颜色
