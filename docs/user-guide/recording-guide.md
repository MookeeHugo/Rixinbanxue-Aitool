## 1. 功能概述

### 什么是服务端录制？

服务端录制是由 LiveKit 云端服务器自动录制直播内容的功能。与客户端录制相比：

| 特性 | 服务端录制 | 客户端录制 |
|------|-----------|-----------|
| 录制质量 | ⭐⭐⭐⭐⭐ 高质量（1080p） | ⭐⭐⭐ 依赖网络 |
| 稳定性 | ⭐⭐⭐⭐⭐ 云端保障 | ⭐⭐⭐ 依赖设备 |
| 存储位置 | 云端自动保存 | 本地需手动上传 |
| 适用场景 | 官方存档、重要课程 | 个人备份 |
| 费用 | 占用存储配额 | 免费 |

**推荐使用场景**:
- ✅ 重要课程的官方录制
- ✅ 需要长期保存的课堂内容
- ✅ 多人观看的公开课
- ❌ 个人测试或临时会议（建议使用客户端录制）

## 2. 开始录制

### 2.1 进入直播间

1. 登录系统（使用教师账号）
2. 进入 **直播** 页面
3. 点击 **创建课堂** 或选择已有课堂
4. 点击 **进入课堂** 按钮

### 2.2 启动服务端录制

在直播间底部控制栏，您会看到两个录制按钮：

```
┌─────────────────────────────────────────────┐
│  [麦克风] [摄像头] [屏幕共享] [白板]          │
│                                              │
│  [开始录制] [⏺️ 开始录制] [挂断]             │
│    ↑客户端     ↑服务端                       │
└─────────────────────────────────────────────┘
```

**点击右侧的 "⏺️ 开始录制" 按钮** (服务端录制)

### 2.3 录制进行中

录制开始后，您会看到：

1. **录制指示器**: 红色脉冲圆点 🔴
2. **录制时长**: 实时显示 (例如: `00:05:23`)
3. **按钮变化**: "开始录制" → "⏹️ 停止录制"

```
┌─────────────────────────────────────────────┐
│  直播中...                    🔴 00:05:23   │
└─────────────────────────────────────────────┘
```

**注意事项**:
- ⚠️ 录制过程中不要关闭浏览器
- ⚠️ 确保网络连接稳定
- ℹ️ 录制会自动保存到云端，无需手动操作

### 2.4 停止录制

1. 点击 **⏹️ 停止录制** 按钮
2. 弹出确认对话框：

```
┌─────────────────────────────────┐
│  确认停止录制                    │
│                                  │
│  您确定要停止当前录制吗？        │
│  录制时长：00:05:23              │
│                                  │
│  [取消]  [确认停止]              │
└─────────────────────────────────┘
```

3. 点击 **确认停止**
4. 录制文件将在后台处理（约 1-2 分钟）

**处理过程**:
1. LiveKit 停止录制
2. 生成 MP4 文件
3. 上传到云端存储
4. 发送完成通知 ✅

## 3. 管理录制文件

### 3.1 查看录制列表

**方法 1: 通过导航菜单**
1. 点击顶部导航栏的 **我的录制**
2. 查看所有录制文件

**方法 2: 通过直播列表**
1. 进入 **直播** 页面
2. 每个课堂卡片显示录制数量
3. 点击 **查看录制** 查看该课堂的所有录制

### 3.2 录制文件信息

每个录制文件显示以下信息：

```
┌─────────────────────────────────────────────┐
│  数学基础练习 - 服务端录制        [已完成]  │
│                                              │
│  初一数学基础知识讲解                        │
│                                              │
│  ⏱️ 12:45  💾 245 MB  📅 2025-11-23        │
│                                              │
│  [▶️ 播放]  [⬇️ 下载]  [🗑️ 删除]           │
└─────────────────────────────────────────────┘
```

**状态说明**:
- 🟢 **已完成**: 可以播放和下载
- 🔵 **处理中**: 正在生成文件，请稍候
- 🔴 **失败**: 录制失败，请联系管理员

### 3.3 播放录制

1. 找到要播放的录制文件
2. 点击 **▶️ 播放** 按钮
3. 在弹出的播放器中观看

**播放器功能**:
- ⏯️ 播放/暂停
- ⏩ 快进/快退
- 🔊 音量控制
- 🖼️ 全屏模式
- ⚙️ 倍速播放（0.5x, 1x, 1.5x, 2x）

### 3.4 下载录制

1. 找到要下载的录制文件
2. 点击 **⬇️ 下载** 按钮
3. 文件将自动下载到您的电脑

**文件信息**:
- 格式: MP4
- 分辨率: 1920x1080
- 编码: H.264
- 音频: AAC

### 3.5 删除录制

⚠️ **删除操作不可恢复，请谨慎操作！**

1. 找到要删除的录制文件
2. 点击 **🗑️ 删除** 按钮
3. 确认删除：

```
┌─────────────────────────────────────────────┐
│  确认删除                                    │
│                                              │
│  确定要删除录制"数学基础练习"吗？            │
│  此操作不可恢复。                            │
│                                              │
│  [取消]  [确认删除]                          │
└─────────────────────────────────────────────┘
```

4. 点击 **确认删除**
5. 文件将从云端永久删除

**删除后**:
- ✅ 释放存储空间
- ✅ 更新配额统计
- ❌ 无法恢复

### 4.1 查看配额使用情况

**位置 1: 录制页面**
在 **我的录制** 页面顶部，可以看到存储配额卡片：


**位置 2: 直播列表页面**
在顶部导航栏可以看到配额徽章：

```

```

### 4.2 配额限制

| 限制类型 | 默认值 | 说明 |
|---------|--------|------|
| 用户总配额 | 5 GB | 每个用户可使用的总存储空间 |
| 单个文件 | 2 GB | 单个录制文件最大大小 |
| 每会话录制数 | 10 个 | 每个直播会话最多录制次数 |

**建议操作**:
1. 查看 **我的录制** 页面
2. 按创建时间排序（最旧的在前）
3. 删除不再需要的录制文件
4. 查看配额更新

**最佳实践**:
- ✅ 定期（每月）清理 30 天以上的录制
- ✅ 下载重要录制到本地后删除云端文件
- ✅ 删除测试或失败的录制
- ✅ 使用客户端录制代替服务端录制（不占配额）

## 5. 常见问题

### Q1: 录制按钮是灰色的，无法点击

**原因**:
- 您不是课堂创建者
- 存储配额已满

**解决**:
1. 确认您是教师账号
2. 检查存储配额是否充足
3. 如果配额已满，删除旧文件后重试

---

### Q2: 录制时长显示不准确

**原因**: 这是实时计时，基于客户端时间

**解决**:
- 最终时长以录制完成后的文件时长为准
- 刷新页面后时长会根据开始时间重新计算

---

### Q3: 录制文件处理失败

**可能原因**:
- 网络中断
- LiveKit 服务异常
- 存储空间不足

**解决**:
1. 检查 **我的录制** 页面，查看状态
2. 如果显示 "失败"，重新录制
3. 联系管理员查看日志

---

### Q4: 无法播放录制文件

**可能原因**:
- 文件还在处理中
- 浏览器不支持 MP4
- 网络连接问题

**解决**:
1. 等待文件状态变为 "已完成"
2. 使用 Chrome/Firefox/Safari 最新版本
3. 尝试下载后本地播放

---

### Q5: 删除文件后配额没有更新

**原因**: 配额统计有 30 秒延迟

**解决**:
- 等待 30 秒后自动刷新
- 或点击配额卡片上的 🔄 刷新按钮

---

### Q6: 同时录制多个会话会怎样？

**答案**: 可以同时录制多个会话

但请注意:
- 每个录制都会占用配额
- 确保总配额足够
- 建议不要同时录制超过 3 个会话

---

### Q7: 录制文件可以分享给其他人吗？

**答案**: 目前仅录制创建者可以查看和下载

如需分享:
1. 下载录制文件到本地
2. 通过其他方式（网盘、邮件等）分享

**未来计划**: 添加分享链接功能

---

### Q8: 录制会包含屏幕共享和白板内容吗？

**答案**: 是的！

服务端录制会捕获：
- ✅ 摄像头画面
- ✅ 屏幕共享内容
- ✅ 白板内容
- ✅ 所有参与者的音频

---

### Q9: 录制的视频质量可以调整吗？

**答案**: 当前使用固定配置

- 分辨率: 1920x1080
- 视频码率: 3 Mbps
- 音频码率: 128 kbps
- 格式: MP4

**未来计划**: 添加质量选项（高/中/低）

---

### Q10: 系统会自动删除旧录制吗？

**答案**: 是的

系统会自动清理：
- 超过 30 天的已完成录制
- 超过 7 天的失败录制

**提醒**: 重要录制请及时下载到本地保存！
