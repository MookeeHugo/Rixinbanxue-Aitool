# 题目卡片内联编辑 - 使用指南

## 📖 功能概述

内联编辑模式允许您直接在题目卡片上编辑题目信息，无需打开弹窗对话框，提供更流畅的编辑体验。

---

## 🎯 快速开始

### 1. 进入编辑模式

在审核页面（`/tools/ingest/{taskId}/review`）中：

1. 找到需要编辑的题目卡片
2. 点击卡片右上角的 **"编辑"** 按钮
3. 卡片会展开显示编辑表单，边框变为蓝色

### 2. 编辑题目内容

编辑表单分为两个标签页：

#### 📝 题目内容

**可编辑字段：**

- **题目类型**：选择题 / 填空题 / 解答题 / 证明题
- **题干**：支持 LaTeX 可视化编辑和原始文本编辑
- **选项**（仅选择题）：添加/删除/编辑选项
- **答案/解析**：支持 LaTeX 可视化编辑和原始文本编辑
- **难度**：简单 / 适中 / 困难
- **知识点**：手动添加知识点标签
- **标签管理**：多维度标签分类，支持 AI 智能推荐

#### 🖼️ 配图管理

**可用功能：**

- **拖拽排序**：在上方网格区域拖拽调整配图顺序
- **配图标签编辑**：为每张配图设置描述性标签
- **图片增强**：对模糊或不清晰的配图进行锐化和降噪处理
- **删除配图**：移除质量不佳或无关的配图

### 3. 保存或取消

- **保存修改**：点击底部的 **绿色"保存修改"** 按钮
- **取消编辑**：点击 **"取消"** 按钮，所有未保存的修改将被放弃

## 🏷️ 标签管理功能详解

### 标签系统架构

标签系统支持以下维度分类：

| 分类 | 说明 | 示例 |
|------|------|------|
| 知识点 | 题目涉及的数学知识点 | 函数图像、立体几何、概率统计 |
| 难度 | 题目难度等级 | 简单、适中、困难 |
| 年级 | 适用年级 | 高一、高二、高三 |
| 题型 | 题目类型 | 选择题、填空题、解答题 |
| 来源 | 试卷来源 | 高考真题、模拟题、校内题 |
| 地区 | 地区分类 | 全国卷、北京卷、上海卷 |
| 考试类型 | 考试场景 | 期中考试、期末考试、月考 |
| 自定义 | 用户自定义标签 | 重点题型、易错题、经典题 |

### 使用标签选择器

1. **点击"添加标签"按钮**
   打开标签选择器弹窗

2. **搜索标签**
   在搜索框输入关键词快速查找标签

3. **常用标签**
   顶部显示您最近常用的标签，可快速选择

4. **分类浏览**
   点击分类 Tab（知识点、难度、年级等）浏览该分类下的所有标签

5. **AI 推荐标签**
   点击 **"AI 推荐"** 按钮，系统会根据题目内容自动推荐相关标签
   - AI 推荐的标签会显示紫色 ✨ 图标
   - 推荐结果基于题目的题干和选项内容

6. **移除标签**
   在已选标签上点击 ❌ 图标即可移除

### 标签最佳实践

✅ **推荐做法：**

- 为每道题目至少添加 1 个知识点标签
- 使用 AI 推荐功能提高标注效率
- 优先使用系统预设标签，便于统计和筛选
- 合理使用自定义标签标记特殊题目

❌ **避免：**

- 避免为同一题目添加过多标签（建议不超过 8 个）
- 避免创建重复或相似的自定义标签
- 避免使用过于宽泛的标签（如"数学题"）

## 🖼️ 配图编辑功能详解

### 配图标签编辑

**用途：** 为配图添加描述性标签，方便后续查找和理解

**操作步骤：**

1. 切换到 **"配图管理"** 标签页
2. 在图片操作列表中，找到需要编辑的配图
3. 直接在输入框中编辑配图标签
4. 点击 **"保存修改"** 保存更改

**标签命名建议：**

- ✅ 好的标签：`图1-函数图像`、`题干配图`、`解析步骤1`
- ❌ 不好的标签：`图片`、`aaa`、`untitled`

### 配图拖拽排序

**用途：** 调整配图的显示顺序，确保配图按正确的顺序呈现

**操作步骤：**

1. 在上方的配图网格区域，按住配图拖动
2. 将配图拖动到目标位置后松开鼠标
3. 配图顺序会自动更新（order 字段）
4. 点击 **"保存修改"** 保存新的顺序

### 配图增强

**用途：** 对模糊或质量不佳的配图进行图像增强处理

**操作步骤：**

1. 在图片操作列表中，点击 **"增强"** 按钮
2. 在增强对话框中选择增强参数：
   - **锐化强度**：1-5 级，提升图片清晰度
   - **降噪强度**：1-5 级，减少图片噪点
3. 点击 **"应用增强"** 生成新配图
4. 确认效果后点击 **"保存修改"**

**注意事项：**

- 增强后的配图会标记为"人工修复"
- 原始配图不会被删除，可以通过重新解析恢复
- 过度增强可能导致图片失真

### 配图删除

**两种删除方式：**

#### 方式 1：编辑模式删除

1. 在图片操作列表中点击 **"删除"** 按钮
2. 确认删除提示
3. 配图从列表中移除（但未立即删除）
4. 点击 **"保存修改"** 后永久删除

#### 方式 2：快捷删除（查看模式）

1. 在查看模式下，将鼠标悬停在配图上
2. 点击右上角出现的 🗑️ **删除图标**
3. 确认删除提示
4. 配图立即从数据库中删除

**区别：**

- 编辑模式删除：需要点击保存后才生效
- 快捷删除：立即生效，无需保存

## 📋 布局顺序说明

### 查看模式

题目卡片按以下顺序展示内容：

1. **题干** - 题目问题描述
2. **选项** - 选择题的候选答案（如果有）
3. **配图** - 题目相关图片（如果有）
4. **答案** - 题目答案或解析
5. **AI 解题步骤** - AI 生成的解题思路（如果有）
6. **知识点** - 旧版知识点标签（如果有）
7. **标签** - 新版多维度标签（如果有）

### 编辑模式

编辑表单分为两个标签页：

#### 题目内容 Tab

1. 题目类型
2. 题干
3. 选项（选择题）
4. 答案/解析
5. 难度
6. 知识点
7. **标签管理** ← 新增

#### 配图管理 Tab

1. 配图拖拽排序区域
2. 图片操作列表（支持标签编辑、增强、删除）

## ⌨️ 快捷操作

### 卡片快捷操作（查看模式）

**配图快捷操作：**

- 将鼠标悬停在配图上，显示快捷操作按钮：
  - ✨ **增强** - 打开图片增强对话框
  - 🗑️ **删除** - 立即删除配图

### 编辑模式快捷操作

**LaTeX 编辑切换：**

- 在题干和答案字段，点击右上角切换按钮：
  - **可视化编辑** - 所见即所得的 LaTeX 编辑器
  - **原始文本** - 直接编辑 Markdown/LaTeX 源码

## 💡 使用技巧

### 提高效率

1. **使用 AI 推荐标签**
   点击"AI 推荐"按钮，快速为题目添加相关标签

2. **使用常用标签**
   系统会记录您常用的标签，下次可快速选择

3. **批量操作**
   如果需要为多道题目添加相同标签，可以使用批量标签功能（即将推出）

4. **快捷删除配图**
   在查看模式下，鼠标悬停配图即可快速删除，无需进入编辑模式

### 避免错误

1. **保存前检查**
   修改完成后，仔细检查所有字段，确保无误后再保存

2. **取消时确认**
   点击"取消"按钮会丢失所有未保存的修改，请谨慎操作

3. **配图标签命名规范**
   使用有意义的配图标签，方便后续查找和理解

## ❓ 常见问题

### Q1: 点击"编辑"按钮后没有反应？

**A:** 检查以下情况：

- 浏览器控制台是否有错误信息
- 是否有权限编辑该题目
- 刷新页面后重试

### Q2: 保存后标签没有显示？

**A:** 可能的原因：

- 标签数据库连接失败
- 刷新页面查看最新数据
- 检查浏览器控制台错误日志

### Q3: AI 推荐标签功能无法使用？

**A:** 检查：

- 题目是否有题干内容（AI 需要分析题目内容）
- 网络连接是否正常
- Gemini API 是否配置正确

### Q4: 配图增强后效果不理想？

**A:** 建议：

- 调整锐化和降噪参数
- 过度增强可能导致失真，建议适度调整
- 如果效果不佳，可以使用"框选修复"功能手动裁剪原图

### Q5: 删除配图后如何恢复？

**A:**

- 编辑模式删除：点击"取消"按钮可恢复
- 快捷删除：无法直接恢复，需要使用"重新解析"功能重新生成配图
