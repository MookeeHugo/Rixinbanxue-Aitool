# 小红书AI运营系统 - 快速开始

## 🚀 立即测试（使用模拟数据）

由于小红书网站结构经常变化，我们提供了**测试模式**，使用模拟数据来演示完整流程。

### 1. 启用测试模式

在项目根目录的 `.env.local` 文件中添加：

```bash
NEXT_PUBLIC_XHS_MOCK_MODE=true
```

### 2. 启动系统

```bash
# 确保数据库运行
pnpm db:status

# 如果数据库未运行，启动它
pnpm db:start

# 启动开发服务器
pnpm dev
```

### 3. 访问系统

1. 打开浏览器访问：http://localhost:3002
2. 登录账号（teacher@test.com / test123456）
3. 点击主页的"📱 小红书AI分析"卡片
4. 或直接访问：http://localhost:3002/xiaohongshu

### 4. 测试完整流程

#### 步骤1：爬取帖子（模拟数据）
- 输入关键词：数学教学
- 点击"开始爬取"
- 系统会返回2个模拟的爆款帖子

#### 步骤2：AI分析
- 在帖子列表中点击"AI分析"
- Gemini会真实分析这些模拟帖子
- 等待10-15秒

#### 步骤3：生成草稿
- 选择人设（如"数学老师-10年经验"）
- 点击"生成草稿"
- DeepSeek会真实重写内容
- 进行原创性检测

#### 步骤4：查看和复制
- 切换到"草稿列表"标签
- 查看原文 vs AI生成的对比
- 使用分段复制按钮复制内容

## 🌐 真实爬虫模式（进阶）

如果您想测试真实的爬虫功能，需要做以下准备：

### 1. 安装Playwright浏览器

```bash
npx playwright install chromium
```

### 2. 禁用测试模式

在 `.env.local` 中设置：

```bash
NEXT_PUBLIC_XHS_MOCK_MODE=false
```

或直接删除该行。

### 3. 小红书选择器可能需要更新

由于小红书经常更新网页结构，如果爬取失败：

1. 查看调试截图：`debug-xiaohongshu-error.png`
2. 打开小红书网站：https://www.xiaohongshu.com
3. 使用开发者工具（F12）查看实际的DOM结构
4. 更新选择器配置：`src/lib/xiaohongshu-crawler/config.ts`

### 4. 常见问题

**Q: 爬取失败怎么办？**
- 检查是否需要登录（小红书可能要求登录）
- 查看控制台日志和调试截图
- 尝试使用代理IP（Phase 2功能）

**Q: 如何获取真实的小红书数据？**
- 手动复制粘贴（最简单）
- 使用浏览器插件导出
- 等待选择器更新
