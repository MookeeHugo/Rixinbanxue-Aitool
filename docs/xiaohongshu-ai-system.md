# 小红书AI运营系统 - 使用说明

## 项目概述

这是一个完整的小红书AI运营自动化系统，帮助教师打造个人IP，通过AI分析爆款帖子并生成原创内容。

## 核心功能

### 1. 智能爬虫模块
- **Playwright自动化爬虫**：无头浏览器爬取小红书爆款帖子
- **反检测策略**：
  - 覆盖webdriver检测
  - 多UA轮换（5个不同User-Agent）
  - 多视口伪装（5种分辨率）
  - Canvas/WebGL指纹混淆
  - 随机鼠标移动和滚动行为
- **重试机制**：3次重试 + 指数退避（1s → 2s → 4s）
- **软封禁检测**：自动检测空列表并停止爬取
- **限制保护**：最多爬取10个帖子/次

### 2. AI分析模块
- **Gemini 2.5 Flash分析器**：
  - 分析爆款帖子的成功因素
  - 识别标题策略、内容结构、互动驱动
  - 成本：~$0.075/1M input tokens
- **分析维度**：
  - 标题策略（如何吸引点击）
  - 内容结构（如何组织内容）
  - 互动驱动因素（至少3个）
  - 目标受众分析
  - 情感诉求
  - 行动号召

### 3. 内容重写模块
- **DeepSeek智能重写**：
  - 根据用户人设重写内容
  - Temperature 0.8提升创意
  - 成本：~$0.14/1M input + $0.28/1M output
- **4个教师人设预设**：
  - 数学老师-10年经验
  - 英语老师-8年经验
  - 编程老师-5年经验
  - 物理老师-12年经验

### 4. 原创性检测模块
- **双重检测机制**：
  - 整体相似度 < 20% 才通过
  - 段落相似度 > 50% 会被标记
- **详细分析**：
  - 整体相似度百分比
  - 最高段落相似度
  - 可疑段落数量
  - 词汇多样性评分

### 5. 配额管理系统
- **三层限制**：
  - 每日爬取限额：50次
  - 每小时爬取限额：10次
  - 每日生成限额：20次
- **自动重置**：每日零点重置配额
- **失败回滚**：爬取/生成失败自动退还配额

## 技术架构

### 数据库层
- **3个核心表**：
  - `xhs_raw_posts` - 爬取的原始帖子
  - `xhs_ai_drafts` - AI生成的草稿
  - `xhs_crawl_quotas` - 配额管理
- **RLS策略**：完整的行级安全控制
- **复合索引**：优化查询性能（crawl_keyword + likes DESC）
- **ON CONFLICT**：自动去重

### 后端层
- **7个Server Actions**：
  - `crawlPosts` - 爬取帖子
  - `analyzePost` - AI分析
  - `generateDraft` - 生成草稿
  - `approveDraft` - 批准草稿
  - `getUserQuota` - 获取配额
  - `getRawPosts` - 获取帖子列表
  - `getDrafts` - 获取草稿列表

### 前端层
- **主页快捷入口**：蓝色渐变卡片
- **爬虫控制台**：关键词搜索 + 配额展示
- **对比视图**：原文 vs AI生成内容
- **一键复制**：标题/正文/标签分别复制

## 使用流程

### 1. 启动数据库
```bash
pnpm db:start
```

### 2. 应用数据库迁移
迁移文件已在之前的`pnpm db:reset`中应用，包含：
- `supabase/migrations/20251210000001_add_xiaohongshu_system.sql`

### 3. 访问系统
1. 登录后在主页点击"📱 小红书AI分析"卡片
2. 进入爬虫控制台

### 4. 爬取爆款帖子
1. 输入关键词（例如：数学教学、初中数学）
2. 设置最低点赞数（默认1000）
3. 选择教师人设
4. 点击"开始爬取"

### 5. AI分析帖子
1. 在帖子列表中找到想要分析的帖子
2. 点击"AI分析"按钮
3. 等待Gemini分析完成（约5-10秒）

### 6. 生成原创内容
1. 分析完成后，点击"生成草稿"
2. 系统自动调用DeepSeek重写
3. 进行原创性检测
4. 显示检测结果

### 7. 查看和复制内容
1. 切换到"草稿列表"视图
2. 查看原文 vs AI生成的对比
3. 使用分段复制按钮：
   - 复制标题
   - 复制正文
   - 复制标签
   - 一键复制全部
4. 手动发布到小红书（最安全方式）

## 注意事项

### 1. 反爬虫维护
- 小红书可能每周更新反爬策略
- 选择器可能需要定期更新（`config.ts`中的`XHS_SELECTORS`）
- 建议每次爬取间隔5-10分钟

### 2. 配额限制
- 每日最多爬取50次
- 每小时最多爬取10次
- 超过限制会自动拒绝

### 3. 原创性要求
- 整体相似度必须 < 20%
- 如果不通过，草稿会被标记为`rejected`
- 建议调整人设或重新生成

### 4. 发布方式
- **MVP阶段**：手动复制粘贴（最安全）
- **Phase 2**：自动发布（需要代理IP + 登录验证）

## 常见问题

### Q1: 爬取失败怎么办？
- 检查网络连接
- 确认关键词是否正确
- 查看是否被软封禁（等待1小时后重试）

### Q2: 原创性检测不通过？
- 尝试更换人设
- 调整关键词（避免使用过于热门的词汇）
- 重新生成草稿

### Q3: 如何提高生成质量？
- 选择合适的人设（与内容主题匹配）
- 爬取高质量爆款帖子（点赞数 > 5000）
- 确保AI分析完成后再生成

### Q4: 配额不够用？
- 目前限制：每日50次爬取 + 20次生成
- 可联系管理员调整（修改数据库中的`daily_crawl_limit`）
