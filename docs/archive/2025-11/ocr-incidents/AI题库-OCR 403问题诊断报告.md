## 🎯 问题定位

### 根本原因

**阿里云OCR服务未正确开通或激活未生效**

这不是代码问题，而是**阿里云账户端的服务激活状态问题**。

### 证据链

1. ✅ 所有配置正确（AccessKey、网络、代码）
2. ✅ API请求成功发送到阿里云服务器
3. ❌ 服务器明确返回 "api is not purchased"
4. 结论: 服务端认为该API未开通

---

## 📋 解决步骤

### 第一步: 确认服务开通状态

1. **访问阿里云OCR控制台**:
   ```
   https://ocr.console.aliyun.com/
   ```

2. **检查服务状态**:
   - 左侧菜单选择 "通用文字识别"
   - 查看页面顶部是否显示 **"已开通"** 状态
   - 如果显示"未开通"或"立即开通"按钮，说明服务确实未激活

3. **重要提示**:
   - 必须是 **"通用文字识别"** 产品
   - 不是"文档识别"或其他OCR产品
   - 产品代码: `ocr20191230`
   - API方法: `RecognizeCharacter`

### 第二步: 开通服务

如果服务未开通，请按以下步骤操作:

1. **点击"立即开通"按钮**

2. **阅读并同意服务协议**

3. **选择计费方式**:
   - 推荐: 按量付费（默认）
   - 免费额度: 5,000次/月
   - 超出后: ¥0.001/次

4. **确认开通**

5. **等待激活生效**:
   - 通常需要 **5-30分钟**
   - 在此期间会持续返回403错误
   - 建议等待10分钟后重新测试

### 第三步: 验证权限配置

如果服务显示"已开通"但仍然403，检查AccessKey权限:

1. **访问RAM控制台**:
   ```
   https://ram.console.aliyun.com/users
   ```

2. **检查RAM用户权限**:
   - 找到对应的RAM用户
   - 点击"权限管理"
   - 确认包含以下权限之一:
     - ✅ `AliyunOCRFullAccess` (推荐)
     - ✅ 或自定义策略包含 `ocr:RecognizeCharacter`

3. **如使用主账号AccessKey**:
   - 主账号默认有所有权限
   - 但仍需确认服务已开通

### 第四步: 测试验证
