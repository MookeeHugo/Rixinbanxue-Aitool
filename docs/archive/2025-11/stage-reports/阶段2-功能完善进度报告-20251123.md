##### startRecording()
```typescript
async startRecording(input: StartRecordingInput): Promise<StartRecordingResult> {
  // 1. 检查是否已有活跃录制
  if (this.activeRecordings.has(input.sessionId)) {
    return { recordingId: existingEgressId };
  }

  // 2. 启动 Egress 录制
  const recordingInfo = await this.egressManager.startRoomRecording({
    sessionId: input.sessionId,
    roomId: input.roomId,
    userId: input.userId,
    layout: 'grid',
    outputConfig: {
      format: 'mp4',
      width: 1920,
      height: 1080,
      videoBitrate: 3000000,  // 3 Mbps
      audioBitrate: 128000,   // 128 kbps
    },
  });

  // 3. 保存活跃录制
  this.activeRecordings.set(input.sessionId, recordingInfo.egressId);

  return { recordingId: recordingInfo.egressId };
}
```

**特点**:
- ✅ 防止重复录制（幂等性）
- ✅ 完整的错误处理
- ✅ 详细的日志记录

##### stopRecording()
```typescript
async stopRecording(input: StopRecordingInput): Promise<void> {
  // 1. 查找 Egress ID
  const egressId = input.recordingId || this.activeRecordings.get(input.sessionId);

  if (!egressId) {
    return; // 没有活跃录制，直接返回
  }

  // 2. 停止 Egress 录制
  await this.egressManager.stopRecording(egressId);

  // 3. 从活跃录制中移除
  this.activeRecordings.delete(input.sessionId);
}
```

**特点**:
- ✅ 支持通过 sessionId 或 recordingId 停止
- ✅ 优雅的错误处理
- ✅ 确保资源清理

### 错误处理

#### 常见错误及解决方案

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| `Egress service not available` | Egress 服务未运行 | 部署 Egress 服务或使用 LiveKit Cloud |
| `Room not found` | 房间不存在 | 确保先创建房间 |
| `Recording already active` | 重复启动录制 | 检查活跃录制状态 |
| `Permission denied` | API 密钥错误 | 验证 LIVEKIT_API_SECRET |
| `Failed to stop recording` | Egress ID 无效 | 验证 recordingId 是否正确 |
