## 🎯 核心特性

### 1. 错题本与学情分析系统 🆕
- **错题自动收集**: 无需手动标注，自动识别错题
- **知识点分析**: 多维度统计每个知识点掌握情况
- **智能评级**: 5级掌握水平自动判定
- **学习建议**: 基于数据生成个性化建议
- **教学诊断**: 帮助教师识别全班薄弱知识点
- **可视化展示**: 进度条、图表、颜色区分

### 2. 作业管理系统
- **班级管理**: 自动生成班级代码，方便学生加入
- **作业发布**: 灵活选择班级、试卷、截止时间
- **在线作答**: 三种题型完整支持
- **自动批改**: 选择题自动判分
- **成绩统计**: 提交率、平均分等统计

### 3. 智能组卷系统
- **灵活配置**: 支持多维度组卷条件
- **随机算法**: 每次组卷结果不同
- **知识点筛选**: 50 个初中数学知识点
- **题型分类**: 选择题、填空题、解答题
- **难度分级**: 简单、中等、困难
- **实时预览**: 组卷后立即预览效果
- **打印功能**: 一键打印标准试卷格式

### 4. 题库管理系统
- **CRUD 操作**: 完整的增删改查
- **富表单**: 支持多种题型的录入
- **知识点标签**: 50 个知识点分类
- **权限控制**: 教师可见共享题库
- **筛选搜索**: 按题型和难度筛选

### 5. 用户认证系统
- **角色区分**: 教师/学生双角色
- **会话管理**: 自动保持登录状态
- **RLS 安全**: 数据库级别权限控制
- **邮箱认证**: Supabase Auth
