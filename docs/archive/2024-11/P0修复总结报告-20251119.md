## 📊 修复概览

### 问题类型
**React Memory Leak - useEffect异步操作未清理**

在组件卸载后，useEffect中的异步操作仍然尝试更新状态，导致：
- 内存泄漏
- React警告："Can't perform a React state update on an unmounted component"
- 潜在的性能问题

## 🔧 修复方案

### 标准修复模式

采用 **mountedRef 清理模式** 作为统一解决方案：

```typescript
useEffect(() => {
  const mountedRef = { current: true }

  const asyncFunction = async (mounted: { current: boolean }) => {
    try {
      // 异步操作前检查
      if (!mounted.current) return

      const result = await someAsyncCall()

      // 状态更新前检查
      if (!mounted.current) return
      setState(result)

    } catch (error) {
      // 错误处理前检查
      if (!mounted.current) return
      handleError(error)
    }
  }

  asyncFunction(mountedRef)

  // 清理函数
  return () => {
    mountedRef.current = false
  }
}, [dependencies])
```

### 关键原则

1. **在每个异步操作后立即检查** `mounted.current`
2. **所有状态更新前必须检查** 组件是否已卸载
3. **错误处理中也要检查** 避免卸载后显示错误
4. **清理函数设置标志** 通知所有异步操作停止

## 📁 修复详情

### 1️⃣ 作业创建页面
**文件**: [src/app/assignments/create/page.tsx](src/app/assignments/create/page.tsx)

**问题**:
- `checkUser()` 异步获取用户信息后更新状态
- `loadData()` 加载班级和试卷列表，包含2个异步操作
- 组件卸载时仍在执行，导致内存泄漏

**修复措施**:
```typescript
// 修改前
const loadData = useCallback(async (userId: string) => {
  setError(null)
  const { data: classesData } = await supabase...
  setClasses(classesData || [])
  const { data: papersData } = await supabase...
  setPapers(papersData || [])
}, [])

// 修改后
const loadData = useCallback(async (userId: string, mounted: { current: boolean }) => {
  if (!mounted.current) return
  setError(null)

  const { data: classesData } = await supabase...
  if (!mounted.current) return
  setClasses(classesData || [])

  const { data: papersData } = await supabase...
  if (!mounted.current) return
  setPapers(papersData || [])
}, [])

useEffect(() => {
  const mountedRef = { current: true }

  const checkUser = async () => {
    const currentUser = await getCurrentUser()
    if (!mountedRef.current) return

    if (!currentUser) {
      router.push('/login')
      return
    }
    setUser(currentUser)
    loadData(currentUser.id, mountedRef)
  }

  checkUser()
  return () => { mountedRef.current = false }
}, [router, loadData])
```

**检查点**: 3个 mounted 检查（checkUser + loadData 2次）

### 6️⃣ 题库管理页面 ⚠️ 特殊处理
**文件**: [src/app/questions/page.tsx](src/app/questions/page.tsx)

**问题**:
- **包含 setInterval 轮询**，每4秒检查导出任务状态
- 3个 useEffect 都有内存泄漏风险
- 定时器未清理会持续执行

**修复措施**:
```typescript
// 定时器清理模式
useEffect(() => {
  const mountedRef = { current: true }

  const timer = setInterval(async () => {
    if (!mountedRef.current) return
    // 轮询逻辑
  }, 4000)

  return () => {
    mountedRef.current = false
    clearInterval(timer)  // 清理定时器
  }
}, [deps])
```

**检查点**: 3个 useEffect，包含特殊的 timer 清理

## 🎯 最佳实践总结

### ✅ Do's（应该做的）

1. **每个异步操作后检查 mounted 状态**
   ```typescript
   if (!mounted.current) return
   ```

2. **在清理函数中设置标志**
   ```typescript
   return () => { mountedRef.current = false }
   ```

3. **定时器必须清理**
   ```typescript
   clearInterval(timer)
   ```

4. **错误处理中也要检查**
   ```typescript
   catch (error) {
     if (!mounted.current) return
     handleError(error)
   }
   ```

### ❌ Don'ts（不应该做的）

1. ❌ 在 useEffect 外部使用 let mounted 变量（作用域问题）
2. ❌ 忘记在清理函数中设置 mounted = false
3. ❌ 只在某些异步操作后检查（必须全部检查）
4. ❌ 使用 AbortController 但忘记调用 abort()
