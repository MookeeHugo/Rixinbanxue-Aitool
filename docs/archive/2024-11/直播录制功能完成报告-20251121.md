## 🗄️ 数据库结构

### 1. `live_recordings` 表

**迁移文件**: `supabase/migrations/20241121000003_add_live_recordings.sql`

```sql
CREATE TABLE live_recordings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id UUID NOT NULL REFERENCES live_sessions(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  description TEXT,
  file_path TEXT NOT NULL,
  file_url TEXT NOT NULL,
  file_size BIGINT,
  duration_seconds INTEGER,
  recorded_by UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  status TEXT NOT NULL CHECK (status IN ('processing', 'completed', 'failed')) DEFAULT 'processing',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**索引**:
- `session_id` - 查询某个课堂的所有录制
- `recorded_by` - 查询某个用户的所有录制
- `created_at DESC` - 按时间排序
- `status` - 筛选已完成的录制

**RLS 策略**:
- ✅ 所有认证用户可以查看录制
- ✅ 录制创建者可以插入
- ✅ 录制创建者可以更新
- ✅ 录制创建者可以删除

### 2. Storage Bucket

**迁移文件**: `supabase/migrations/20241121000004_create_recordings_storage.sql`

**Bucket**: `live-recordings` (公开访问)

**存储策略**:

## 🔧 技术实现

### 录制流程

```
1. 用户点击"开始录制"
   ↓
2. 请求屏幕共享权限 (getDisplayMedia)
   ↓
3. 请求麦克风权限 (getUserMedia)
   ↓
4. 合并多个音视频轨道
   ↓
5. 创建 MediaRecorder (VP9/Opus, 2.5Mbps)
   ↓
6. 开始录制，实时显示时长
   ↓
7. 用户点击"停止录制"
   ↓
8. 停止所有媒体流
   ↓
9. 合并 Blob 块
   ↓
10. 自动上传到 Supabase Storage
    ↓
11. 保存元数据到数据库
    ↓
12. 提示用户录制完成
```

### 优化措施

1. **编码优化**:
   - VP9 优先，回退到 VP8
   - 2.5 Mbps 比特率（平衡质量和大小）
   - 1080p 分辨率目标

2. **音频优化**:
   - 回声消除 (echoCancellation)
   - 噪音抑制 (noiseSuppression)
   - 44.1kHz 采样率

3. **错误处理**:
   - 权限被拒绝提示
   - 录制失败自动清理
   - 上传失败重试提示

4. **用户体验**:
   - 实时录制时长显示
   - 红点动画指示录制中
   - 上传进度提示
   - 自动保存和清理

## 📝 代码示例

### 在组件中使用录制功能

```typescript
import { useMediaRecorder } from '@/hooks/useMediaRecorder';

function MyComponent() {
  const {
    isRecording,
    recordingDuration,
    startRecording,
    stopRecording,
    uploadRecording,
  } = useMediaRecorder();

  const handleStart = async () => {
    const result = await startRecording();
    if (!result.success) {
      alert(`录制失败: ${result.error}`);
    }
  };

  const handleStop = async () => {
    stopRecording();
    // 录制会自动上传
  };

  return (
    <div>
      <button onClick={handleStart} disabled={isRecording}>
        开始录制
      </button>
      <button onClick={handleStop} disabled={!isRecording}>
        停止录制 ({recordingDuration}s)
      </button>
    </div>
  );
}
```
