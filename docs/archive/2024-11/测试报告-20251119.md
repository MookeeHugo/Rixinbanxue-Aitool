## 📈 修复详情

### ✅ 修复 #1: 学生作业提交测试登录超时
**问题**: 测试超时 33.7秒，登录按钮显示"登录中..."
**根本原因**:
- 测试同时使用了 `storageState` 和 `ensureLoggedIn()`
- 两种认证方式冲突，导致 `ensureLoggedIn()` 尝试访问 `/questions` 时学生被重定向

**修复方案**:
1. 移除 `beforeEach` 中的 `ensureLoggedIn()` 调用
2. 仅依赖 `playwright/.auth/student.json` 的 storageState
3. 修改测试访问 `/my-assignments`（学生页面）而不是 `/assignments`（教师页面）
4. 添加空数据处理逻辑，优雅地跳过无数据场景

**修复文件**:
- [tests/e2e/student-assignments.spec.ts](tests/e2e/student-assignments.spec.ts)

**结果**: ✅ 测试时间从 33.7s 降至 2.5s，成功通过

---

### ✅ 修复 #2: 题篮清空对话框交互问题
**问题**: 点击"清空"按钮超时，无法完成题篮清空测试
**根本原因**:
1. 确认按钮文本是"清 空"（中间有空格），测试代码查找"清空"（无空格）
2. 清理阶段的硬删除流程过于复杂，模态框交互不稳定
3. 多个"删除"按钮导致 strict mode 冲突

**修复方案**:
1. 修改选择器使用正则表达式 `/清\s*空/` 匹配空格
2. 简化清理逻辑，使用软删除代替硬删除
3. 使用 `exact: true` 精确匹配按钮名称
4. 添加更好的错误处理和等待时间
5. 重命名重复变量避免语法错误

**修复文件**:
- [tests/e2e/questions.spec.ts:154-197](tests/e2e/questions.spec.ts#L154-L197)

**结果**: ✅ 测试时间 12.2s，成功通过所有步骤（批量导出/导入 + 题篮操作 + 清空 + 清理）
