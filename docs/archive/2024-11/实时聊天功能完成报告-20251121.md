## 📋 技术实现

### 1. 数据库表结构

**表名**：`live_chat_messages`

**字段**：
```sql
CREATE TABLE live_chat_messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id UUID NOT NULL REFERENCES live_sessions(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  message TEXT NOT NULL,
  message_type TEXT NOT NULL CHECK (message_type IN ('text', 'system', 'raise_hand')) DEFAULT 'text',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

**索引**：
- `idx_live_chat_messages_session_id` - 按会话查询
- `idx_live_chat_messages_user_id` - 按用户查询
- `idx_live_chat_messages_created_at` - 按时间排序

**RLS 策略**：
- ✅ 所有认证用户可以查看聊天消息
- ✅ 所有认证用户可以发送聊天消息（仅限自己的用户ID）
- ✅ 用户只能删除自己的消息

### 3. 前端组件

**文件**：`src/components/live/LiveChat.tsx`

**核心功能**：

#### 加载历史消息
```typescript
// 组件加载时获取历史消息
useEffect(() => {
  async function loadMessages() {
    const response = await fetch(`/api/live-sessions/${sessionId}/messages`);
    const data = await response.json();
    setMessages(data);
    setTimeout(scrollToBottom, 100);
  }

  if (sessionId) {
    loadMessages();
  }
}, [sessionId]);
```

#### Supabase Realtime 订阅
```typescript
// 订阅新消息
useEffect(() => {
  const channel = supabase
    .channel(`live_chat:${sessionId}`)
    .on(
      "postgres_changes",
      {
        event: "INSERT",
        schema: "public",
        table: "live_chat_messages",
        filter: `session_id=eq.${sessionId}`,
      },
      async (payload) => {
        // 获取完整消息（包括用户信息）
        const { data: newMsg } = await supabase
          .from("live_chat_messages")
          .select(`..., profiles:user_id (id, name, role)`)
          .eq("id", payload.new.id)
          .single();

        setMessages((prev) => [...prev, newMsg]);
        setTimeout(scrollToBottom, 100);
      }
    )
    .subscribe();

  return () => {
    supabase.removeChannel(channel);
  };
}, [sessionId]);
```

#### 发送消息
```typescript
const handleSendMessage = async (e: React.FormEvent) => {
  e.preventDefault();

  const response = await fetch(`/api/live-sessions/${sessionId}/messages`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      message: newMessage.trim(),
      messageType: "text",
    }),
  });

  const sentMessage = await response.json();
  setMessages((prev) => [...prev, sentMessage]);
  setNewMessage("");
};
```

### 预期问题排查

#### 问题 1：消息不实时更新

**症状**：发送消息后，对方看不到或需要刷新

**排查**：
1. 检查浏览器控制台是否有错误
2. 查看网络标签，确认 WebSocket 连接成功
3. 检查 Supabase Realtime 订阅状态：
   ```
   console: "Realtime订阅状态:", "SUBSCRIBED"
   ```

**解决方案**：
- 确保 Supabase 本地服务正在运行
- 检查 `.env.local` 配置是否正确
- 重启 Supabase：`npx supabase stop && npx supabase start`

#### 问题 2：发送消息失败

**症状**：点击发送后，消息未出现或显示错误

**排查**：
1. 检查浏览器控制台错误信息
2. 检查网络请求是否返回 401/403/500

**可能原因**：
- 未登录或 session 过期 → 重新登录
- RLS 策略阻止 → 检查数据库策略
- API 路由错误 → 查看服务器日志

#### 问题 3：历史消息不加载

**症状**：刷新后看不到之前的消息

**排查**：
1. 检查 API 请求：`/api/live-sessions/[id]/messages`
2. 查看响应是否为空数组或错误

**可能原因**：
- 数据库查询失败 → 检查 Supabase 日志
- session_id 不匹配 → 确认 URL 参数正确

**使用示例**：
```typescript
const channel = supabase.channel(`live_chat:${sessionId}`)

    event: 'INSERT',
    schema: 'public',
    table: 'live_chat_messages',
```
