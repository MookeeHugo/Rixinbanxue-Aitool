### ❌ Don'ts（不应该做的）

1. ❌ 输出详细的结构化错误日志
   ```typescript
   // ❌ 调试代码
   console.error('[function] Error:', {
     code, message, details, hint
   })
   ```

2. ❌ 输出成功操作日志
   ```typescript
   // ❌ 生产环境噪音
   console.log('操作成功')
   ```

3. ❌ 输出敏感信息
   ```typescript
   // ❌ 安全风险
   console.log('Session:', session)
   console.log('Token:', accessToken)
   ```
