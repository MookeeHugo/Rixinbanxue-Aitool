## 🔒 安全修正详情

### 1. Supabase 反向代理安全加固

#### ❌ 原问题描述

**漏洞位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L415-L440)

**严重等级**: 🔴 P0 - 严重 (可导致数据泄露/越权操作)

**问题代码**:
```typescript
// ❌ 危险：接受任意表名、方法和请求体
export default async function handler(req: Request) {
  const { tableName, method, body, filters } = await req.json();

  // 直接转发到 Supabase，没有任何限制
  const url = `${SUPABASE_URL}/rest/v1/${tableName}?${filterStr}`;
  const response = await fetch(url, {
    method,
    headers: {
      'apikey': SUPABASE_ANON_KEY,
      'Authorization': `Bearer ${SUPABASE_ANON_KEY}`,
    },
    body: method !== 'GET' ? JSON.stringify(body) : undefined,
  });
}
```

**安全风险**:
1. ⚠️ 攻击者可访问**任意数据表** (users、profiles、financial_records 等)
2. ⚠️ 可绕过前端权限直接调用 DELETE/POST/PATCH
3. ⚠️ 可注入恶意过滤器 (filters 未校验)
4. ⚠️ 使用匿名密钥,无法触发 RLS 用户级权限

**攻击示例**:
```javascript
// 恶意请求：窃取所有用户数据
fetch('/api/supabase-proxy', {
  method: 'POST',
  body: JSON.stringify({
    tableName: 'users',        // 访问敏感表
    method: 'GET',
    filters: { role: 'admin' } // 获取管理员信息
  })
});

// 恶意请求：删除题库
fetch('/api/supabase-proxy', {
  method: 'POST',
  body: JSON.stringify({
    tableName: 'questions',
    method: 'DELETE',
    filters: {} // 删除所有记录
  })
});
```

#### ✅ 修正方案

**修正位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L415-L503)

**修正策略**:
1. ✅ **路由白名单**: 仅允许访问业务必需的4个表
2. ✅ **JWT 身份验证**: 强制用户登录,传递真实 token 触发 RLS
3. ✅ **输入过滤白名单**: 仅允许安全字段作为过滤条件
4. ✅ **方法限制**: 每个表仅允许必要的 HTTP 方法
5. ✅ **错误码规范**: 403/401/500 明确区分错误类型

**修正代码**:
```typescript
// ✅ 安全：路由白名单 + JWT 验证 + 输入过滤
import { createClient } from '@supabase/supabase-js';

const SUPABASE_URL = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const SUPABASE_ANON_KEY = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!;

// 1️⃣ 路由白名单：仅允许业务必需的表和方法
const ALLOWED_ROUTES = {
  'questions': ['GET', 'POST', 'PATCH'],      // 题目查询、创建、更新
  'question_baskets': ['GET', 'POST', 'DELETE'], // 题篮管理
  'memberships': ['GET'],                     // 班级成员查询（只读）
  'export_tasks': ['GET', 'POST'],           // 导出任务查询、创建
} as const;

export default async function handler(req: Request) {
  const { tableName, method, body, filters } = await req.json();

  // 2️⃣ 验证表名和方法是否在白名单内
  if (!ALLOWED_ROUTES[tableName as keyof typeof ALLOWED_ROUTES]) {
    return new Response(
      JSON.stringify({ error: 'Access to this table is forbidden' }),
      { status: 403 }
    );
  }

  const allowedMethods = ALLOWED_ROUTES[tableName as keyof typeof ALLOWED_ROUTES];
  if (!allowedMethods.includes(method as any)) {
    return new Response(
      JSON.stringify({ error: `Method ${method} not allowed on ${tableName}` }),
      { status: 403 }
    );
  }

  // 3️⃣ JWT 身份验证：从请求头提取真实用户 token
  const authHeader = req.headers.get('Authorization');
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return new Response(
      JSON.stringify({ error: 'Unauthorized: Missing or invalid token' }),
      { status: 401 }
    );
  }

  const userToken = authHeader.substring(7); // 去掉 "Bearer "

  // 4️⃣ 验证 token 有效性
  const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
  const { data: { user }, error: authError } = await supabase.auth.getUser(userToken);

  if (authError || !user) {
    return new Response(
      JSON.stringify({ error: 'Unauthorized: Invalid token' }),
      { status: 401 }
    );
  }

  // 5️⃣ 输入过滤白名单：仅允许安全字段
  const SAFE_FILTER_KEYS = ['id', 'user_id', 'subject_id', 'grade_id', 'class_id'];
  const safeFilters = Object.entries(filters || {})
    .filter(([key]) => SAFE_FILTER_KEYS.includes(key))
    .map(([key, value]) => `${key}=eq.${value}`)
    .join('&');

  // 6️⃣ 透传用户 token，触发 RLS 权限控制
  const url = `${SUPABASE_URL}/rest/v1/${tableName}?${safeFilters}`;
  const response = await fetch(url, {
    method,
    headers: {
      'apikey': SUPABASE_ANON_KEY,
      'Authorization': `Bearer ${userToken}`,  // ✅ 使用真实用户 token
      'Content-Type': 'application/json',
    },
    body: method !== 'GET' ? JSON.stringify(body) : undefined,
  });

  // 7️⃣ 错误处理
  if (!response.ok) {
    return new Response(
      JSON.stringify({ error: 'Supabase request failed', details: await response.text() }),
      { status: response.status }
    );
  }

  const data = await response.json();
  return new Response(JSON.stringify(data), { status: 200 });
}
```

### 2. 对象存储文件公开访问加固

#### ❌ 原问题描述

**漏洞位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L317-L330)

**严重等级**: 🔴 P0 - 严重 (敏感数据泄露)

**问题代码**:
```typescript
// ❌ 危险：所有文件上传到公开桶
async function uploadFile(file: Buffer, key: string) {
  const command = new PutObjectCommand({
    Bucket: 'rixing-public',  // ❌ 所有文件公开
    Key: key,
    Body: file,
    ContentType: 'application/pdf',
  });

  await r2.send(command);

  // ❌ 返回公开 URL，任何人都可访问
  return `https://cdn.rixing.com/${key}`;
}
```

**安全风险**:
1. ⚠️ **学生作业答案 PDF** 公开,可提前泄露
2. ⚠️ **成员导出数据** (手机号、邮箱) 公开,违反隐私法
3. ⚠️ **批改意见附件** 公开,学生可互相查看
4. ⚠️ **题目解析 PDF** 公开,失去付费价值

**攻击示例**:
```javascript
// 恶意访问：遍历猜测文件名，下载所有导出数据
for (let i = 1; i <= 1000; i++) {
  fetch(`https://cdn.rixing.com/exports/members-${i}.pdf`);
}
```

---

#### ✅ 修正方案

**修正位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L317-L386)

**修正策略**:
1. ✅ **文件分级**: 区分公开文件 (PUBLIC) 和私有文件 (PRIVATE)
2. ✅ **双桶隔离**: 公开桶 + 私有桶物理隔离
3. ✅ **签名 URL**: 私有文件生成 1 小时临时 URL
4. ✅ **权限校验**: 下载前验证用户权限
5. ✅ **动态 MIME**: 根据文件扩展名自动设置 ContentType

**修正代码**:

**1. 文件访问级别定义**:

**2. 动态 MIME 类型检测**:
```typescript
// ✅ MIME 类型映射表
const MIME_TYPES: Record<string, string> = {

  'png': 'image/png',
```

**3. 安全上传函数**:
```typescript
// ✅ 安全：根据文件类型选择桶，动态 MIME
async function uploadFile(
  file: Buffer,
  key: string,
  accessLevel: FileAccessLevel = FileAccessLevel.PRIVATE,
  contentType?: string
): Promise<{ publicUrl?: string; privateKey?: string }> {

  // 1️⃣ 自动检测 MIME 类型
  const detectedContentType = contentType || getMimeType(key);

  // 2️⃣ 根据访问级别选择桶
  const bucket = accessLevel === FileAccessLevel.PUBLIC
    ? 'rixing-public'
    : 'rixing-private';

  const command = new PutObjectCommand({
    Bucket: bucket,
    Key: key,
    Body: file,
    ContentType: detectedContentType,  // ✅ 动态 MIME
  });

  await r2.send(command);

  // 3️⃣ 公开文件返回 CDN URL，私有文件返回 key
  if (accessLevel === FileAccessLevel.PUBLIC) {
    return { publicUrl: `https://cdn.rixing.com/public/${key}` };
  } else {
    return { privateKey: key };
  }
}
```

**4. 签名 URL 生成**:
```typescript
// ✅ 安全：私有文件生成临时签名 URL
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';
import { GetObjectCommand } from '@aws-sdk/client-s3';

async function generateSignedUrl(
  key: string,
  userId: string,
  expiresIn: number = 3600  // 默认 1 小时
): Promise<{ url: string; expiresAt: Date }> {

  // 1️⃣ 权限校验
  const hasPermission = await checkFilePermission(key, userId);
  if (!hasPermission) {
    throw new Error('User does not have permission to access this file');
  }

  // 2️⃣ 生成签名 URL
  const command = new GetObjectCommand({
    Bucket: 'rixing-private',
    Key: key,
  });

  const signedUrl = await getSignedUrl(r2Private, command, { expiresIn });

  return {
    url: signedUrl,
    expiresAt: new Date(Date.now() + expiresIn * 1000),
  };
}
```

**5. 权限校验函数**:
```typescript
// ✅ 安全：验证用户是否有权访问文件
async function checkFilePermission(key: string, userId: string): Promise<boolean> {
  // 导出文件：仅创建者可访问
  if (key.startsWith('exports/')) {
    const taskId = key.split('/')[1].replace('.pdf', '');
    const task = await supabase
      .from('export_tasks')
      .select('user_id')
      .eq('id', taskId)
      .single();
    return task.data?.user_id === userId;
  }

  // 作业提交：仅学生本人和任课教师可访问
  if (key.startsWith('assignments/submissions/')) {
    const submissionId = key.split('/')[2];
    const submission = await supabase
      .from('submissions')
      .select('student_id, assignment:assignments(teacher_id)')
      .eq('id', submissionId)
      .single();

    return submission.data?.student_id === userId
        || submission.data?.assignment.teacher_id === userId;
  }

  // 其他私有文件：默认拒绝
  return false;
}
```

```typescript
// src/app/api/files/download/route.ts
export async function POST(req: Request) {
  const { key } = await req.json();

  // 1️⃣ 身份验证
  const session = await getServerSession();

    );
  }
}
```

### 3. ContentType 固定导致功能异常修正

#### ❌ 原问题描述

**漏洞位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L317)

**严重等级**: 🟡 P1 - 高 (功能异常,影响用户体验)

**问题代码**:
```typescript
// ❌ 危险：ContentType 固定为 PDF
const command = new PutObjectCommand({
  Bucket: 'rixing-public',
  Key: key,
  Body: file,
  ContentType: 'application/pdf',  // ❌ 写死
});
```

**功能风险**:
1. ⚠️ 上传 PNG 题目配图,浏览器强制下载而非展示
2. ⚠️ 上传 MP4 视频讲解,无法在线播放
3. ⚠️ 上传 JSON 配置文件,显示为乱码
4. ⚠️ CDN 缓存策略异常 (PDF 缓存 7 天,图片应缓存 30 天)

**用户影响**:
```javascript
// 上传题目配图
uploadFile(imageBuffer, 'questions/images/geometry-1.png');
// ❌ CDN 返回 Content-Type: application/pdf
// ❌ 浏览器强制下载，而非显示图片

// 上传视频讲解
uploadFile(videoBuffer, 'videos/lesson-1.mp4');
// ❌ CDN 返回 Content-Type: application/pdf
// ❌ 浏览器无法播放视频
```

#### ✅ 修正方案

**修正位置**: [日新平台_升级计划_v5.md](日新平台_升级计划_v5.md#L317-L330)

**修正策略**:
1. ✅ **MIME 类型映射表**: 覆盖常见文件格式
2. ✅ **自动检测**: 根据文件扩展名自动设置
3. ✅ **手动覆盖**: 支持手动传入 contentType 参数
4. ✅ **默认回退**: 未知格式使用 `application/octet-stream`

**修正代码** (已在修正 2 中实现):
