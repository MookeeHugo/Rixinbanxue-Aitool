# 数据驱动的决策触发条件表

> **文档版本**: v2.4
> **更新日期**: 2025-01-14
> **适用场景**: Hugo独立运营日新教学平台
> **目标**: 用数据指导关键决策，避免凭感觉决策

---

## 📊 使用说明

本文档提供**明确的数据阈值**，告诉Hugo"何时该做什么决策"。

### 核心原则

1. **数据驱动**: 所有决策基于客观数据，不靠感觉
2. **触发条件**: 每个决策都有明确的触发条件（阈值）
3. **月度检查**: 每月1-5号检查数据，判断是否需要决策
4. **快速执行**: 触发条件满足后，立即执行行动

### 如何使用

1. **每月1号**: 更新Google Sheets数据看板（见附录）
2. **每月2号**: 对照本文档的触发条件表，判断是否需要决策
3. **每月3号**: 如果需要决策，制定行动计划
4. **每月5号**: 执行决策

## 🎯 决策1：是否招聘运营专员（¥10k/月）

### 触发条件（必须全部满足）

| 条件 | 阈值 | 说明 |
|------|------|------|
| ✓ 注册教师数 | > 100人 | 用户规模够大，需要专人运营 |
| ✓ 月活跃教师 | > 30人 | 至少发布1次作业的教师数 |
| ✓ 试用→付费转化率 | > 20% | 产品价值被验证 |
| ✓ 现金储备 | > ¥120k | 足够支付12个月工资 |

### 判断逻辑

- **如果用户数少**: Hugo自己能应付客服和运营
- **如果转化率低**: 说明产品有问题，招运营也无济于事
- **如果现金不足**: 招人是找死

### Hugo的行动

#### 每月1号：收集数据

从Supabase后台获取：

1. **注册教师数**
   - 路径: Supabase → Authentication → Users
   - 筛选: role='teacher'
   - 记录总数

2. **月活跃教师**
   - 路径: Supabase → SQL Editor
   - SQL查询:
   ```sql
   SELECT COUNT(DISTINCT teacher_id)
   FROM assignments
   WHERE created_at >= '2025-XX-01'
   AND created_at < '2025-XX+1-01'
   ```
   - 替换日期为本月

3. **付费用户数**
   - 路径: Supabase → Table Editor → subscriptions表
   - 筛选: status='active'
   - 记录总数

4. **转化率**
   - 计算: 付费用户 / 注册教师
   - 示例: 25 / 100 = 25%

5. **现金储备**
   - 查看银行账户余额
   - 记录实际金额

#### 决策判断

- **如果4条全部满足** → 在招聘网站发布JD，开始招聘
- **如果不满足** → 继续单干，下个月再看

#### 招聘行动（如果触发）

- [ ] 在BOSS直聘/拉勾网发布运营专员JD
- [ ] 职责: 用户增长、社群运营、内容营销、用户反馈收集
- [ ] 薪资: ¥10,000/月（全职）
- [ ] 要求: 有教育行业运营经验优先

## ⚠️ 决策2：是否暂停营销投入（¥4.5k/月）

### 触发条件（满足任一条即暂停）

| 条件 | 阈值 | 说明 |
|------|------|------|
| ✗ 现金储备 | < ¥150k | 现金流危机 |
| ✗ 月新增付费用户 | < 10人（连续2个月） | 增长停滞 |
| ✗ 月留存率 | < 70% | 产品有问题 |

### 判断逻辑

- **现金不足** → 暂停烧钱，保命
- **增长停滞** → 营销ROI太低，停掉
- **留存差** → 产品有问题，先修产品再营销

### Hugo的行动

#### 每月5号：检查数据

1. **现金储备**: 查看银行账户余额
2. **本月新增付费用户**: 本月付费用户 - 上月付费用户
3. **上月付费用户本月续费数量**:
   - 查询subscriptions表
   - 统计上月status='active'且本月仍为'active'的用户数
   - 留存率 = 续费数量 / 上月付费用户

#### 决策判断

- **如果任一红线触发** → 立即暂停营销
- **如果全部正常** → 继续投放

#### 暂停行动（如果触发）

- [ ] 停掉公众号外包（¥1,500/月）
- [ ] 停掉视频制作外包（¥2,000/月）
- [ ] 停掉短视频平台投放（¥1,000/月）
- [ ] 保留SEO文章（成本低，¥1,500/月）

- **增长快** → 投资人愿意投
- **NPS高** → 产品被认可
- **现金少** → 真的需要钱

### Hugo的行动

#### 每季度检查（第3、6、9、12个月）

1. **月收入**: 查看Google Sheets数据看板
2. **MoM增长率**: 查看过去3个月的增长率
3. **NPS**: 查看最近一次用户问卷结果
4. **现金储备**: 查看银行账户余额

#### 决策判断

- **如果满足** → 开始准备BP、找FA、约投资人
- **如果不满足** → 继续自力更生

#### 融资行动（如果触发）

- [ ] 准备商业计划书（BP）
  - 使用AI辅助生成（参考ai-prompt-templates.md）

  - 联系早期项目FA

- [ ] 融资时间线: 预计3-6个月完成

## 📊 附录：Google Sheets数据看板创建指南

### 目标

为Hugo创建一个简单易用的数据看板，无需编程知识，每月5分钟更新。

### Step 1: 创建Google Sheets文档

- [ ] 访问 https://sheets.google.com
- [ ] 点击"空白"创建新文档
- [ ] 重命名为"日新教学平台运营数据看板"
- [ ] 创建3个工作表（Sheet）:
  - Sheet1: 重命名为"月度数据"
  - Sheet2: 重命名为"决策触发器"
  - Sheet3: 重命名为"用户增长趋势"

### Step 2: 设置"月度数据"工作表

**表格结构（A1:K20）**:

| 列 | 字段名 | 说明 |
|----|--------|------|
| A | 月份 | M3, M4, M5... |
| B | 注册教师 | 累计注册教师数 |
| C | 月活教师 | 本月发布作业的教师数 |
| D | 付费用户 | 本月付费用户数 |
| E | 月收入 | 本月总收入（元） |
| F | 现金储备 | 银行账户余额（元） |
| G | MoM增长率 | 月收入环比增长率 |
| H | 留存率 | 付费用户续费比例 |
| I | NPS | 净推荐值 |
| J | 备注 | 重要事件记录 |
| K | 转化率 | 付费用户/注册教师 |

**关键公式**:

1. **G列（MoM增长率）**:
   - G2单元格: `="-"`（首月无法计算）
   - G3单元格: `=TEXT((E3-E2)/E2,"0%")`
   - 复制G3到G4:G20

2. **H列（留存率）**:
   - H2单元格: `="-"`（首月无法计算）
   - H3单元格: `=TEXT(1-(D3-D2)/D2,"0%")`
   - 复制H3到H4:H20

3. **K列（转化率）**:
   - K2单元格: `=TEXT(D2/B2,"0%")`
   - 复制K2到K3:K20

### Step 3: 设置"决策触发器"工作表

**表格结构（A1:E10）**:

| A列 | B列 | C列 | D列 | E列 |
|-----|-----|-----|-----|-----|
| 决策项 | 触发条件 | 当前值 | 是否触发 | 行动 |

**第2行（招聘运营专员）**:
- A2: `招聘运营专员`
- B2: `注册>100 且 月活>30 且 转化>20% 且 现金>¥120k`
- C2: `=月度数据!B3&" / "&月度数据!C3&" / "&月度数据!K3&" / "&月度数据!F3`
- D2: `=IF(AND(月度数据!B3>100, 月度数据!C3>30, 月度数据!K3>0.2, 月度数据!F3>120000),"✓ 立即启动","✗ 暂不触发")`
- E2: `发布JD，开始招聘`

**第3行（暂停营销）**:
- A3: `暂停营销投入`
- B3: `现金<¥150k 或 新增<10人 或 留存<70%`
- C3: `=月度数据!F3&" / 新增"&月度数据!D3-月度数据!D2&"人 / 留存"&月度数据!H3`
- D3: `=IF(OR(月度数据!F3<150000, (月度数据!D3-月度数据!D2)<10, 月度数据!H3<0.7),"⚠️ 立即暂停","✓ 继续投放")`
- E3: `停掉公众号、视频外包`

**第4行（启动融资）**:
- A4: `启动融资`
- B4: `收入>¥30k 且 MoM>30% 且 NPS>50 且 现金<¥200k`
- C4: `=月度数据!E3&" / "&月度数据!G3&" / NPS "&月度数据!I3&" / 现金"&月度数据!F3`
- D4: `=IF(AND(月度数据!E3>30000, VALUE(SUBSTITUTE(月度数据!G3,"%",""))/100>0.3, 月度数据!I3>50, 月度数据!F3<200000),"✓ 可以启动","✗ 条件未满足")`
- E4: `准备BP，联系FA`

## 📝 常见问题FAQ

### Q1: 公式显示错误怎么办？

**A**: 检查单元格引用是否正确（如B3改为B4），确保引用的是正确的行号

### Q2: 如何添加更多月份数据？

**A**: 直接在下一行输入数据，公式会自动复制（或手动拖动单元格右下角的小方块）

### Q3: 如何修改触发条件？

**A**: 在"决策触发器"工作表的D列公式中，修改数字阈值（如100改为150）

### Q4: 能否用Excel代替Google Sheets？

**A**: 可以，但Google Sheets的优势是：
- 云端自动保存
- 手机也能访问
- 未来可接入自动化工具（Zapier等）
- 可分享给投资人/顾问查看
