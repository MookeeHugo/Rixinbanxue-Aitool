# AI 创作功能 API 测试指南

## 📋 前置准备

### 1. 创建测试用户

在 Supabase Dashboard 中创建测试用户：

1. 访问 Supabase Studio：`http://localhost:54323`
2. 导航到 **Authentication** > **Users**
3. 点击 **Add user** > **Create new user**
4. 填写信息：
   - Email: `test@rixinmath.com`
   - Password: `Test123456!`
   - 勾选 **Auto Confirm User**
5. 点击 **Create user**

### 2. 配置环境变量

确保 `.env.local` 文件包含以下配置：

```bash
# DeepSeek API（必需）
DEEPSEEK_API_KEY=sk-xxxxx
DEEPSEEK_MODEL=deepseek-reasoner
DEEPSEEK_REQUEST_TIMEOUT=60000

# E2B Sandbox（必需）
E2B_API_KEY=e2b_xxxxx
E2B_TIMEOUT_MS=15000

# Supabase（必需）
NEXT_PUBLIC_SUPABASE_URL=http://localhost:54321
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxx

# Cloudflare R2（必需）
R2_ACCOUNT_ID=xxxxx
R2_ACCESS_KEY_ID=xxxxx
R2_SECRET_ACCESS_KEY=xxxxx
R2_BUCKET_NAME=rixinmath-diagrams
```

### 3. 启动开发服务器

```bash
pnpm dev
```

确保服务运行在 `http://localhost:3000`

### 方式一：直接运行测试脚本

```bash

```

### 方式二：使用 NPM 脚本

在 `package.json` 中添加（如果还没有）：

```json
{

```

然后执行：

```bash
pnpm test:ai-creator
```

## 🔍 查询监控日志

### 在 Supabase Studio 中查询

```sql
-- 查看最近的测试记录
SELECT
  created_at,
  status,
  error_message,
  extra->>'diagram_type' as diagram_type
FROM ai_creation_monitor_logs
ORDER BY created_at DESC
LIMIT 20;

-- 统计成功率
SELECT
  status,
  COUNT(*) as count,
  ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER(), 2) as percentage
FROM ai_creation_monitor_logs
WHERE created_at > now() - interval '1 hour'
GROUP BY status
ORDER BY count DESC;

-- 查看失败原因分布
SELECT
  error_message,
  COUNT(*) as count
FROM ai_creation_monitor_logs
WHERE status != 'success'
  AND created_at > now() - interval '1 hour'
GROUP BY error_message
ORDER BY count DESC
LIMIT 10;
```

## 🐛 常见问题

### 1. 测试用户登录失败

**错误**: `❌ 登录失败: Invalid login credentials`

**解决方案**:
1. 确认测试用户已在 Supabase 中创建
2. 检查 `.env.test` 或 `.env.local` 中的 `TEST_USER_EMAIL` 和 `TEST_USER_PASSWORD`
3. 确认用户已确认（Auto Confirm User）

### 2. API 请求超时

**错误**: `DeepSeek 请求超时`

**解决方案**:
1. 检查 DeepSeek API Key 是否有效
2. 增加 `DEEPSEEK_REQUEST_TIMEOUT` 至 60000 (60秒)
3. 检查网络连接

### 3. E2B 沙箱执行失败

**错误**: `代码执行失败`

**解决方案**:
1. 检查 E2B API Key 是否有效
2. 确认 E2B 账户有剩余配额
3. 检查 `E2B_TIMEOUT_MS` 设置（建议 15000）

### 4. R2 存储失败

**错误**: `图片上传失败`

**解决方案**:
1. 确认 R2 凭据正确
2. 检查 bucket 名称是否正确
3. 验证 R2 bucket 的 CORS 配置
