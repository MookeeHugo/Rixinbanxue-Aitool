## 🔍 根本原因分析

### 核心发现

**上传流程需要用户认证**

查看 [src/app/actions/question-upload.ts:21-28](../src/app/actions/question-upload.ts#L21-L28):

```typescript
export async function uploadQuestionFile(formData: FormData): Promise<ActionResult<UploadResult>> {
  try {
    // 1. 验证用户身份
    const supabase = createAuthenticatedSupabaseClient();
    if (!supabase) {
      return { success: false, error: '未登录，请先登录' };  // ❌ 认证失败
    }

    const { data: { user }, error: authError } = await supabase.auth.getUser();
    if (authError || !user) {
      return { success: false, error: '未登录，请先登录' };  // ❌ 用户未登录
    }

    // ... 只有认证通过才会继续 ...
```

**关键点**:
- 上传必须登录
- 如果未登录，会返回 `{ success: false, error: '未登录，请先登录' }`
- **不会创建任何数据库记录**

### 可能的原因

#### 1. 用户未登录 (最可能)
- **现象**: 点击上传后收到红色错误提示："未登录，请先登录"
- **原因**: Supabase Auth session 过期或不存在
- **结果**: 上传被拒绝，数据库无记录

#### 2. 用户未点击"开始上传"按钮
- **现象**: 选择了文件，但没有点击"开始上传"按钮
- **原因**: UI 流程需要两步：1) 选择文件 → 2) 点击"开始上传"
- **结果**: FormData 从未提交到服务器

#### 3. 客户端 JavaScript 错误
- **现象**: 点击按钮无反应
- **原因**: 浏览器控制台有 JavaScript 错误
- **结果**: 上传函数未执行

#### 4. 网络请求被拦截
- **现象**: 请求发出但被浏览器/防火墙拦截
- **原因**: CORS、CSP、或浏览器扩展拦截
- **结果**: 请求未到达服务器

## ✅ 解决方案

### 方案 1: 确保已登录

**如果看到"未登录"错误**:

```bash
# 1. 访问登录页面
http://localhost:3002/auth/login  # 或你的登录页面路径

# 2. 使用测试账号登录
Email: test@example.com
Password: test123456

# 3. 登录成功后返回上传页面
http://localhost:3002/tools/ingest  # 或你的上传页面路径

# 4. 重新上传文件
```

**如果没有测试账号**:

```bash
# 创建测试账号
http://localhost:3002/auth/signup  # 或注册页面

# 或使用 Supabase Dashboard 创建:
1. 打开 http://127.0.0.1:54323
2. 进入 Authentication → Users
3. 点击 "Add user" 创建测试用户
```

### 方案 2: 完整上传测试流程

```bash
# 详细步骤：
1. 确认已登录（页面右上角显示用户信息）
2. 打开浏览器控制台 (F12)
3. 切换到 Console 选项卡（观察错误）
4. 切换到 Network 选项卡（观察网络请求）
5. 选择一个测试图片文件（JPG/PNG，< 20MB）
6. 确认文件名和大小显示正确
7. 点击"开始上传"按钮
8. 观察：
   - 按钮变为"上传中..."
   - Network 中出现请求
   - Console 中无错误
   - 页面右上角出现成功提示
```

### 方案 3: 使用诊断脚本实时监控

```bash
# 打开新终端，运行监控脚本
npm run watch-uploads

# 或直接运行
npx tsx scripts/watch-uploads.ts

# 该脚本会：
1. 实时监控数据库
2. 检测到新上传任务后显示详细信息
3. 自动测试图片 URL 是否可访问
4. 60 秒后自动退出
```

**同时操作**:
1. 终端 1: 运行监控脚本
2. 浏览器: 执行上传操作
3. 观察终端输出:
   - 如果检测到上传 → 说明认证和上传都成功
   - 如果一直显示"等待上传任务" → 说明上传未成功提交
