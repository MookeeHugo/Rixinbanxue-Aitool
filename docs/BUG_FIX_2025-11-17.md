# Bug 修复总结 - 2025-11-17

## 修复的问题

### 1. ✅ 登录后导航栏不自动刷新

**问题描述**:
- 用户登录成功后，导航栏仍显示"登录、注册"按钮
- 不会自动更新为"题库管理、智能组卷、作业管理、班级管理、教学分析、李老师(教师)"

**根本原因**:
- 登录页使用客户端路由 `router.push('/')` 跳转
- Navbar 组件只在挂载时加载一次用户信息
- 没有监听 Supabase auth 状态变化

**解决方案**:
```typescript
// src/components/Navbar.tsx
useEffect(() => {
  loadProfile()

  // 监听 Supabase auth 状态变化，确保登录/登出时导航栏自动更新
  const { data: authListener } = supabase.auth.onAuthStateChange(
    async (event, session) => {
      if (event === 'SIGNED_IN' && session) {
        // 用户登录，重新加载 profile
        await loadProfile()
      } else if (event === 'SIGNED_OUT') {
        // 用户登出，清除 profile
        setProfile(null)
      }
    }
  )

  return () => {
    authListener.subscription.unsubscribe()
  }
}, [])
```

### 2. ✅ 全站文字颜色对比度不足

**问题描述**:
用户报告多个页面文字看不清楚，包括：
- 首页: "智能组卷 · 自动批改 · 学情分析"
- 登录页: "还没有账号？ 点击注册"
- 题库页: "新建题目" 按钮文字
- 试卷页: 各种说明文字
- 作业页、班级页: 表格和状态文字

**根本原因**:
- 大量使用 `text-muted-foreground` 类，颜色为 `#8e8e93`
- 白色背景上 `#8e8e93` 的对比度仅为 **3.4:1**
- WCAG AA 标准要求最少 **4.5:1**

**解决方案**:
将所有 muted 文字颜色从 `#8e8e93` (浅灰) 改为 `#555555` (深灰):
- 对比度提高到 **7.5:1** (符合 WCAG AAA 标准)

**修改的文件和位置**:

1. **src/app/globals.css**:
   - `.text-muted-foreground`: `#8e8e93` → `#555555`
   - `.rx-muted`: `#8e8e93` → `#555555`
   - `.rx-footer`: `#8e8e93` → `#555555`

2. **src/app/layout.tsx**:
   - `--muted-foreground`: `240 3% 56%` (#8e8e93) → `0 0% 33%` (#555555)
   - `colorTextTertiary`: `#8e8e93` → `#555555`

3. **tailwind.config.ts**:
   - `text-tertiary`: `#8e8e93` → `#555555`

4. **src/components/Navbar.tsx**:
   - 用户名显示从 `text-muted` 改为 `text-foreground-secondary`
