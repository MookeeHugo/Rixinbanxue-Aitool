## 2. Live 模块
- **LiveKit SDK 类型不匹配**：`src/lib/live/egress.ts`、`src/lib/live/providers/livekit.ts` 中对 `StartRecordingInput`、`EncodedFileOutput`、`S3Upload` 等类型的使用与 SDK 定义不符，导致多处 `Property 'sessionId' does not exist` 与 `Type 'unknown' is not assignable` 的编译错误。需要根据最新 LiveKit Server SDK 手动声明接口或封装转换层。
- **错误对象统一缺失**：`logger.ts`、`server/auth.ts`、`server/store.ts`、`storage/quota.ts` 等文件仍向 `logger.error` 传入 `{ error }` 字段，但 `BaseAppError` 类型未包含该属性，应增加自定义接口或统一 `Logger` 的签名。

## 3. Superdesign VSCode 扩展
- **AI SDK 事件流未覆盖**：`customAgentService.ts` 对 `tool-call-streaming-start`、`tool-call-delta`、`step-start` 等事件缺乏类型声明，导致 `TS2678`。需要对 `ai` 包的 `ToolCallPart`、`ToolResultPart` 扩展或在本地补充类型守卫。

- **外部依赖声明不足**：虽然已添加 `@types/vscode` 与自定义 `@anthropic-ai/claude-code` 声明，但 `superdesign/src/services/claudeApiProvider.ts` 等文件仍需要更完整的类型定义，以便 `tsc` 通过。
