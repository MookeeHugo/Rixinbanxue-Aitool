## ROI 分析

### 场景: 月调用10,000次

#### 方案A: 腾讯云OCR API

**优点**:
- ✅ 零部署成本
- ✅ 无需服务器运维
- ✅ 高准确率 (95%+)
- ✅ 稳定可靠

**缺点**:
- ❌ 月成本 ¥1,350
- ❌ 依赖外部服务
- ❌ 网络延迟 (50-200ms)

**适用场景**:
- 快速上线验证
- 不想维护服务器
- 用量不大 (<5,000次/月)

#### 方案B: 云服务器 + PaddleOCR

**优点**:

## 成本优化建议

### 优化1: 按需启动服务器

如果用量波动大，可以使用按量付费的服务器：

```
高峰期 (工作日): 启动服务器
低峰期 (周末): 关闭服务器 + 使用腾讯云API兜底

节省: 约40%服务器成本
```

### 优化2: 缓存机制

对于重复图片（如模板题目），可以缓存OCR结果：

```
缓存命中率: 30%
调用量下降: 10,000 → 7,000次
节省: ¥450/月 (腾讯云方案)
```

### 优化3: 批量处理

批量上传图片时，可以本地处理：

```
单次处理: 10张图片 → 10次API调用
批量处理: 10张图片 → 1次API调用 (合并图片)

成本降低: 90%
```

### 优化4: 混合方案

```
简单图片 (文字清晰): 使用Tesseract (免费)
复杂图片 (手写/模糊): 使用腾讯云OCR

预估: 70%走Tesseract, 30%走腾讯云
调用量下降: 10,000 → 3,000次
节省: ¥1,050/月
```

## 附录: API调用示例

### Node.js调用示例

```typescript
import TencentCloud from 'tencentcloud-sdk-nodejs';

const OcrClient = TencentCloud.ocr.v20181119.Client;

const client = new OcrClient({
  credential: {
    secretId: process.env.TENCENT_SECRET_ID,
    secretKey: process.env.TENCENT_SECRET_KEY,
  },
  region: 'ap-guangzhou',
});

export async function recognizeImage(imageBuffer: Buffer) {
  const params = {
    ImageBase64: imageBuffer.toString('base64'),
  };

  const response = await client.GeneralBasicOCR(params);

  return {
    blocks: response.TextDetections.map(item => ({
      type: 'text',
      text: item.DetectedText,
      confidence: item.Confidence / 100,
      bbox: [
        item.Polygon[0].X,
        item.Polygon[0].Y,
        item.Polygon[2].X - item.Polygon[0].X,
        item.Polygon[2].Y - item.Polygon[0].Y,
      ]
    }))
  };
}
```
