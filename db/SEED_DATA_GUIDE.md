## 🔄 重新导入数据

如果需要清空数据重新导入:

```sql
-- 清空提交记录
DELETE FROM submissions WHERE student_id = '你的学生UUID';

-- 清空作业
DELETE FROM assignments WHERE created_by = '你的教师UUID';

-- 清空试卷
DELETE FROM papers WHERE created_by = '你的教师UUID';

-- 清空班级
DELETE FROM classes WHERE teacher_id = '你的教师UUID';

-- 清空题目
DELETE FROM questions WHERE created_by = '你的教师UUID';
```

然后重新执行 `seed-test-data.sql` 脚本。

## ⚠️ 注意事项

1. **UUID 必须正确**: 确保替换的 UUID 是正确的用户 ID
2. **先注册后导入**: 必须先注册账号，再执行数据脚本
3. **数据隔离**: 测试数据只会关联到指定的教师和学生账号

## 📞 常见问题

### Q1: 脚本执行报错 "Foreign key violation"
**A**: 检查 teacher_id 和 student_id 是否正确，确保用户已注册且 profiles 表中有对应记录。

### Q2: 学生看不到作业
**A**: 当前实现简化了班级-学生关联，所有已发布的作业都会显示给所有学生。如需完整实现，需要添加 class_students 表。

### Q3: 错题本是空的
**A**: 确保学生已提交作业，且提交的答案与正确答案不同。可以查看 submissions 表确认数据是否插入。

### Q4: 教学分析没有数据
**A**: 检查作业是否发布（status='published'），且学生已提交。
